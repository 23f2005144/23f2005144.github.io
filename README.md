### 🏠 Abode Mantra (V2): End-to-End Service Platform
**Type:** Single-Page Application (SPA) | **Role:** Full Stack Developer

A multi-user web application designed for Admins, Customers, and Service Professionals. This version upgrades the original V1 system to a **Single-Page Application (SPA)** using **Vue.js**, enabling faster navigation, dynamic UI updates, and asynchronous background jobs.

**[📂 View Project Repository](https://github.com/23f2005144/Household-Services-App-V2)**

#### 🛠 Tech Stack
* **Backend:** Python 3.12, Flask, Flask-SQLAlchemy, Flask-Security-Too, Flask-RESTful, Flask-Caching
* **Async & Database:** Celery, Redis, SQLite
* **Frontend:** Vue 2, Vue-Router, Vuex, Bootstrap, Chart.js, Flatpickr.js, HTML, CSS, JavaScript (ES6)
* **Utilities:** WeasyPrint (PDF generation), pyexcel / Flask-Excel (CSV exports), smtplib (Email scheduling)

#### ⚙️ Architecture & Features
* **SPA Architecture:** Built with Vue state management and a RESTful API with 11 endpoints.
* **Async Workflows:** Background task scheduling using **Celery + Redis**.
* **Automation:** Automated hourly reminders and monthly service summary reports via email.
* **Data Handling:** CSV export of service request data and dynamic PDF report generation.
* **Security:** Role-based access control and password hashing.

#### 👥 Core Capabilities
* **Admin:** Manage services (CRUD), approve/reject professionals, monitor requests, block/unblock users, view summaries.
* **Customer:** Book, cancel, and close services; view and rate services; track history; receive monthly reports.
* **Professional:** Accept service requests, manage workload, track ratings, receive automated reminders.

### 🚚 Optimizing Revenue for Freight Forwarding
**Context:** Business Data Management (BDM) Capstone | **Duration:** 6 Months

An independent capstone project analyzing and optimizing revenue for a multinational freight forwarding company operating across India. The project tackled stagnant revenue caused by underutilized markets, weak marketing, and inefficient data management.

**[📂 View Project Repository](https://github.com/23f2005144/BDM-Capstone-Project)**

#### 🎯 Problem Statement
The company faced stagnant revenue growth due to:
* Underutilized market segments.
* Weak marketing practices and limited digital presence.
* Inefficient data management.

#### 🔍 Approach & Methodology
1.  **Proposal Stage:** Identified causes of revenue stagnation and defined data collection methodology.
2.  **Mid-Term Stage:**
    * Collected and cleaned Direct Shipment sales data.
    * Analyzed revenue, profit, and shipment metrics.
    * Conducted Segment and Ratio analysis.
3.  **Final-Term Stage:**
    * Performed Trend, Cross-segment, and KPI analysis.
    * Conducted quantitative and qualitative evaluation to develop strategic recommendations.

#### 💡 Key Recommendations
* Focus on high-value segments and underperforming branches.
* Improve digital CRM systems and data management.
* Strengthen digital marketing presence and implement targeted strategies.

#### 🛠 Tools Used
* Microsoft Excel, Structured Analytical Reporting.
